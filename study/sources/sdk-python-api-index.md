# API Reference for TypeSafe AI Python Clients

Página-índice da referência de API do SDK Python da TypeSafe. Aponta para o índice completo de documentação em `https://docs.typesafe.ai/llms.txt` para descobrir todas as páginas disponíveis.

A referência cobre os seguintes componentes:

- **Client Options**: implementações "Sync client" e "Async client", para escolher conforme a necessidade de assincronia.
- **Type Definitions**: três categorias de tipos documentadas — Common types, Questions types e Responses types — que descrevem as estruturas de dados usadas pela API.
- **Supporting Resources**: documentação de Retries, Exceptions e Constants, cobrindo tratamento de erros, lógica de retry e configuração do sistema.

Esse layout permite que desenvolvedores Python localizem rapidamente a documentação específica de API que precisam para integrar a TypeSafe AI em suas aplicações.

Subpáginas listadas no índice oficial (llms.txt), não buscadas individualmente:
- Clients: `sdk/python/api/clients/async.md`, `sdk/python/api/clients/sync.md`
- Types: `sdk/python/api/types/questions.md`, `sdk/python/api/types/responses.md`, `sdk/python/api/types/common.md`
- Retries: `sdk/python/api/retries.md`
- Exceptions: `sdk/python/api/exceptions.md`
- Constants: `sdk/python/api/constants.md`
